about this app:
Naadhe Admin is the official administration app for the Naadhe platform. It is designed exclusively for authorized administrators to manage platform operations efficiently.

With Naadhe Admin, you can:

Review and approve property registrations
Manage users and property owners
Monitor properties and occupancy
View platform-wide statistics
Handle approvals and administrative tasks
Monitor tenant and property data
Manage support requests
Ensure smooth platform operations

Key Features

Property approval workflow
User management
Platform monitoring
Occupancy insights
Secure administrator access
Fast and intuitive interface

Note: This app is intended for authorized Naadhe administrators only. PG owners and property managers should use the Naadhe: PG & Property Manager app.
